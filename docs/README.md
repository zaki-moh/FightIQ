# FightIQ Documentation

This folder contains project documentation for architecture, API behavior, setup, and code ownership.

## Documents

- `docs/architecture.md`: End-to-end system architecture and request flow
- `docs/backend.md`: Backend module responsibilities and design notes
- `docs/frontend.md`: Frontend route/component structure and UX flow
- `docs/api.md`: Backend HTTP endpoints, inputs, and response shapes
- `docs/data-model-and-storage.md`: Storage strategy (CSV vs DB), schema, and seeding
- `docs/development.md`: Local development, environment variables, and common workflows
- `docs/file-map.md`: Source-level file map for quick onboarding

## Suggested Reading Order

1. `docs/architecture.md`
2. `docs/data-model-and-storage.md`
3. `docs/backend.md`
4. `docs/api.md`
5. `docs/frontend.md`
6. `docs/development.md`
